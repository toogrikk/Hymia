## ✨ Основні можливості цифрового продукту

1. **Інтерактивна Періодична система з візуалізацією закономірностей:**
   * **Перемикання градієнтних теплових карт (трендів):**
     * **Електронегативність ($\chi$):** наочне зростання в періодах зліва направо і в групах знизу вгору.
     * **Радіус атома (pm):** зміна розмірів атомів по групах і періодах.
     * **Валентні електрони ($e^-$):** залежність від номера групи головних підгруп.
   * **Фільтрація за класами елементів:** лужні метали, лужноземельні, перехідні метали, напівметали, неметали, галогени, благородні гази з ефектом фокусного підсвічування.
   * **Миттєвий живий пошук:** за символом (наприклад, `Na`), назвою українською (`Оксиген`) або порядковим номером (`11`).
   * **Жива модель Бора (HTML5 Canvas):** візуалізація ядра та електронів, що фізично обертаються на енергетичних рівнях ($K, L, M, N...$), повні електронні конфігурації, ступені окиснення та наукові факти.

2. **Інтерактивна Вікторина & Квест:**
   * 6 практичних тестових завдань на розуміння періодичних залежностей та електронної будови.
   * Миттєві детальні роз'яснення для закріплення знань.
   * Підрахунок балів, присвоєння кваліфікації (*«Магістр Хімії»*) та святкове конфетті при відмінному результаті.

3. **Бездоганна мобільна адаптивність (Mobile-First):**
   * Повна оптимізація для смартфонів (без горизонтального зсуву, адаптовані кнопки, горизонтальна прокрутка таблиці з підказкою, компактні картки інспектора).
