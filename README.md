## ✨ Основні можливості та інтерактивні модулі

1. **Інтерактивна Періодична система з візуалізацією закономірностей:**
   * Підсвічування градієнтних теплових карт (теплова карта електронегативності $\chi$, карта радіусів атомів, валентні електрони).
   * Фільтрація за групами (лужні, галогени, інертні гази, метали, неметали тощо).
   * Живий пошук за назвою, символом або атомним номером.
   * **Анімована модель Бора (HTML5 Canvas):** візуалізація ядра та електронів, що обертаються на енергетичних рівнях ($K, L, M, N...$).

2. **«Конструктор хімічного зв'язку» (Фізико-хімічний симулятор):**
   * Вибір будь-яких двох елементів або швидких пресетів ($NaCl$, $H_2O$, $HCl$, $O_2$, $CH_4$, $Fe-Fe$).
   * Динамічний розрахунок різниці електронегативностей ($\Delta\chi$).
   * Симуляція 4 типів зв'язку:
     * **Йонний зв'язок:** анімація відриву електрона, політ в іонний шар, утворення катіона ($+$) і аніона ($-$) та сили Кулона.
     * **Ковалентний полярний:** зміщення електронної хмари до більш електронегативного атома ($\delta^+$, $\delta^-$).
     * **Ковалентний неполярний:** абсолютно симетрична електронна хмара спільних пар.
     * **Металічний:** вузли кристалічної ґратки та рухливий «електронний газ».

3. **ШІ-Помічник «Хемікус» (AI Chemist Bot):**
   * Інтерактивний діалоговий помічник з базою хімічних знань українською мовою.
   * Відповідає на запитання про природу зв'язку в сполуках, закономірності зміни радіуса, пояснює правило октету простими словами.

4. **Хімічний Квест & Вікторина:**
   * 6 інтерактивних запитань для перевірки знань з миттєвим розбором кожної помилки.
   * Підрахунок балів, присвоєння звання («Магістр Хімії») та святковий феєрверк (конфетті).

5. **Звуковий супровід:**
   * Синтезовані через Web Audio API звуки кліків, утворення зв'язку та перемоги (без потреби завантажувати сторонні файли, можна вимкнути кнопкою в шапці).

## 🚀 Як опублікувати сайт на GitHub Pages (безкоштовно)

Сайт розроблено на чистих веб-технологіях (HTML5, сучасний CSS3 та JavaScript). Він **не потребує складання (build)** чи серверів, тому ідеально публікується на GitHub Pages за 2 хвилини:

### Крок 1. Створіть репозиторій на GitHub
1. Перейдіть на [GitHub.com](https://github.com) і натисніть кнопку **«New»** (новий репозиторій).
2. Назвіть репозиторій, наприклад: `chempulse` або `himia`.
3. Зробіть його **Public** (Публічним) і натисніть **«Create repository»**.

### Крок 2. Завантажте файли
У терміналі (або PowerShell) у папці проєкту виконайте команди:
```bash
git init
git add .
git commit -m "Initial commit of ChemPulse interactive chemistry lab"
git branch -M main
git remote add origin https://github.com/<ВАШ_НІК>/<НАЗВА_РЕПОЗИТОРІЮ>.git
git push -u origin main
```
*(Або просто перетягніть файли проєкту через кнопку «Upload files» у браузері на сторінці вашого репозиторію).*

### Крок 3. Увімкніть GitHub Pages
1. У вашому репозиторії відкрийте вкладку **Settings** (Налаштування) ➔ розділ **Pages** (зліва в меню).
2. У пункті **Build and deployment** під написом **Branch** оберіть гілку `main` та папку `/ (root)`.
3. Натисніть **Save**.
4. Зачекайте 1 хвилину — у верхній частині сторінки з'явиться зелене повідомлення з посиланням:
   `Your site is live at https://<ваш_нік>.github.io/<назва_репо>/`

Це посилання додавайте до свого завдання в Google Classroom!
