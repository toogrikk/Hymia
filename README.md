## ✨ Основні можливості цифрового продукту

1. **Модуль 1: Інтерактивний Конструктор та природа хімічного зв'язку:**
   * **Моделювання утворення зв'язку в реальному часі:**
     * **Йонний зв'язок ($\Delta\chi > 1.7$):** перехід електрона від металу до неметалу, виникнення катіонів та аніонів ($NaCl, CaO$).
     * **Ковалентний полярний зв'язок ($0.4 < \Delta\chi \le 1.7$):** зміщення спільної електронної пари до більш електронегативного атома ($HCl, H_2O$).
     * **Ковалентний неполярний зв'язок ($\Delta\chi \le 0.4$):** симетричний розподіл спільних електронних пар ($O_2, H_2, CH_4$).
     * **Металічний зв'язок:** усуспільнений рухливий «електронний газ» навколо катіонів металу в кристалічній ґратці ($Fe, Cu$).
   * **Швидкі навчальні пресети:** $NaCl, H_2O, HCl, O_2, CH_4, Fe-Fe$.
   * **Розрахунок за шкалою Полінга ($\Delta\chi = |\chi_1 - \chi_2|$):** миттєве прогнозування типу зв'язку, формули Льюїса, кристалічної ґратки та фізичних властивостей речовини.

2. **Модуль 2: Електронегативність, валентність та будова атомів:**
   * **Візуалізація трендів:**
     * **Електронегативність ($\chi$):** зростання в періодах зліва направо та в групах знизу вгору (Флуор = 3.98).
     * **Валентні електрони ($e^-$) та правило октету:** кількість електронів на зовнішньому енергетичному рівні.
     * **Радіус атома ($pm$):** вплив на силу притягання валентних електронів.
   * **Жива модель Бора (HTML5 Canvas):** візуалізація ядра та електронів, що обертаються на енергетичних рівнях ($K, L, M, N...$), повні електронні конфігурації, ступені окиснення та кнопка швидкого переходу до конструктора зв'язку.

3. **Модуль 3: Інтерактивна Вікторина & Квест:**
   * 6 практичних тестових запитань, адаптованих спеціально під програму 11 класу з теми «Хімічний зв'язок» (початок вивчення на 22.10.2026).
   * Миттєві детальні роз'яснення для закріплення кожного питання.
   * Підрахунок балів, присвоєння звання (*«Магістр Хімічного Зв'язку»*) та святкове конфетті при відмінному результаті.

4. **Бездоганна мобільна адаптивність (Mobile-First):**
   * Повна оптимізація під будь-які екрани (смартфони, планшети, ПК).
   * Чистий веб-стек (HTML5, Vanilla CSS3, ES6 JavaScript, Canvas 2D) без важких залежностей.
